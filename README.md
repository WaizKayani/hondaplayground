# Honda × OSU AI Playground

Prototype student–engineer project matching demo developed through The Ohio State University's Center for Software Innovation in collaboration with Honda. This v1 MVP focuses on student-to-project matchmaking for instructor and sponsor demonstrations.

## Tech stack

- Next.js (App Router)
- React
- JavaScript
- Plain CSS
- Node.js / npm

Data is stored in the browser with `localStorage`. There is no database, authentication, or external API.

## Installation

```bash
npm install
```

## Running locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Vercel deployment

Deployed on vercel https://hondaplayground.vercel.app

## Browser-local demo data

All students, projects, and applications are saved in the current browser only. Data does not sync across devices or users. Use **Reset Demo** in the navigation bar to restore the original sample data.
